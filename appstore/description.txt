A polished combination timer, alarm and stopwatch designed for quick-launch.
For everyday use for cooking, reminders and alarms.
Packed with unique, detailed behaviour to optimise frequent use.

Specifically, this does 3 things I couldn't find anywhere else:
    - Start counting immediately on launch
    - Show all 4 relevant values (alarm time, duration, remaining, elapsed) at all times
    - Modify the duration at any point without any pause or confirmation

Other features:
    - Timer modification controls optimised for speed (1h, 5m, 1m increments)
    - Battery saving:
        - Auto switch between seconds/minutes update rate, synced with backlight and/or remaining time
        - Zero background power use
        - Auto-cancel alarm vibe after 1m
    - Runs in background, auto-opens for alarm
    - Counts overtime after alarm vibe
    - After expiry, set a new alarm from the same base just by increasing the duration again
    - Short vibe on start/stop for blind operation
    - Glance info in system app launcher
    - Pause, resume, restart, reset

Planned updates:
    - Touchscreen control (as soon as API is available)
    - App configuration (colours, battery saving options, any other requested features)

Controls:
    - Select/Back to choose modification digits (15/30 seconds available while under 2/5mins)
    - Up/Down to increment/decrement. Hold to repeat. Down at 0 wraps up.
    - Select Long-press (or Press at lowest digit)
       to toggle pause/resume and enter "control mode":
        - Up (rewind icon) to restart the timer (i.e. set elapsed time to 0)
           while retaining the timer/alarm duration
        - Up Long-press to reset the entire app to 0
        - Select (play/pause icon) to pause/resume counting
        - Down (X icon) to discard timer/alarm and exit the app
        - Back to return to timer modification
    - Back while at the largest digit to exit with options:
        - Up/Back (save icon) to save and exit
        - Down (X icon) to discard timer/alarm and exit the app
        - Select (> icon) to return to timer modification
    - Back Long-press to save and exit
    - Any button to dismiss alarm bell

This app is great if you want to:
    - Set a stopwatch/timer running fast without looking in the middle of cooking,
       and then change it as you go along
    - Often quickly set an alarm to remind you about something in the near future
    - Set a wakeup alarm quick at a varying time just before you go to sleep
    - Do all of the above with a single app using one quick-launch slot

Use (a) different app(s) if you want:
    - More than one alarm/timer/stopwatch at once
    - To slowly set a timer/alarm to a long but precise time
    - Automatically repeat alarms daily/weekly
    - Millisecond precision
    - Sports-stopwatch split times / lap times
    - A history of previously set times
    - Voice control

This is based on an unreleased app I made just for myself for an android smartwatch years ago, which ended up being the only thing I ever used it for, daily. Watches are primarily for dealing with time after all, and I just can't find any other timer app that does what I want! Now redesigned and polished for release on pebble in the hope that I'm not an alien freak and this is useful for someone else too :P.
